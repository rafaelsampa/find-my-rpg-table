# Playground

Esta pasta serve como um **playground** para o desenvolvimento e experimentação do SaaS. Aqui você pode testar ideias, escrever rascunhos em ```.md``` e criar protótipos de forma independente.

## Objetivo

- Testar funcionalidades e conceitos.  
- Criar rascunhos e protótipos.  
- Trabalhar com arquivos isolados.  

## Observações

- Este repositório não contém código de produção.  
- Os arquivos aqui são independentes e não fazem parte do sistema principal.  

Sinta-se à vontade para explorar e experimentar!
